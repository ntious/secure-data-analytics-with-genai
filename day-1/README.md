# Day 1: AI Literacy, Prompt Engineering, and Responsible Use

## Session description

Day 1 introduces participants to AI, generative AI, and large language models at a practical level. Participants examine how these systems work, their useful applications, their limitations, structured prompting methods, and responsible use in research, teaching, writing, coding, and knowledge work.

## Learning outcomes

- Explain core AI, GenAI, and LLM concepts in accessible terms.
- Describe practical uses of GenAI in research, teaching, writing, and knowledge work.
- Apply structured prompting techniques to improve AI outputs.
- Use AI tools for literature-review support, academic writing, idea generation, and coding assistance.
- Recognize ethical, privacy, bias, copyright, academic-integrity, and accuracy concerns.

## Expected preparation

Bring a computer with a modern browser. If local exercises are announced, install Python and Jupyter in advance. Use only facilitator-approved AI services and do not submit confidential, personal, unpublished, or institutionally restricted content.

## Recommended sequence

1. Review the session goals and responsible-use expectations.
2. Work through AI and LLM foundations.
3. Practice structured prompting.
4. Apply prompts to research, teaching, writing, and coding scenarios.
5. Complete the group activity and discuss risks and validation.
6. Continue with the [curated supplementary resources](docs/supplementary-resources.md).

## Completion checklist

- [ ] I can explain AI, GenAI, and LLMs in practical terms.
- [ ] I can write a structured prompt with context, task, constraints, and output format.
- [ ] I can identify privacy, bias, copyright, integrity, and accuracy risks.
- [ ] I verify important AI outputs rather than treating them as authoritative.
- [ ] I know what information must not be submitted to an external AI service.

## Troubleshooting

See [Troubleshooting](#troubleshooting) below.

- If a resource is absent, confirm whether it is marked as planned.
- If Jupyter is unavailable, use a facilitator-approved local notebook environment.
- If an AI tool is unavailable, complete the prompt-design exercise without submitting the prompt.
- Never work around an access problem by uploading restricted information to another service.
